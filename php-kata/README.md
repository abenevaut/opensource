Get started with PHP through exercises.

## Objectives

- understand the basics of PHP for local development
- understand and practice PHP scripting in command line
- learn and practice basic web application
- use popular tools from the ecosystem

## Prerequisite

- a basic understanding of what is a software may be necessary
- be confortable with your operating system (OS)

ℹ️ Note: Except the first tutorial to install PHP, all exercises are demonstrated on Apple Silicon, but they are not specific to this environment.

## Exercises

Each directory contains an exercise to complete:
- the `readme.md` file contains the exercise description
- the `readme.md` file contains the solution
- other files in the directory illustrate the build context for a binary or service that needs to run in a container
