Get started with Management through exercises.

## Objectives

- get (at least) some basics of team management and organisation
- understand and practice management exercices
- get informed of tools that can help you to track your team

## Prerequisite

- a basic understanding of what is a team may be necessary
- be confortable with your self, as manager

## Exercises

Each directory contains an exercise to complete:
- the `readme.md` file contains the exercise description
- the `readme.md` file contains a possible solution
- other files in the directory illustrate the context
